# כספת פרופיל כרום ניידת (Chrome Profile Portable Vault)

יישום נייד ומאובטח המאפשר לך לגבות את כל נתוני פרופיל ה-Google Chrome שלך (כולל חיבור לחשבון גוגל, עוגיות / Cookies, היסטוריה והגדרות) לתוך קובץ כספת מוצפן המוצמד ליישום, לשחזר אותו בלחיצת כפתור בכל מחשב, ולמחוק את העקבות מהמחשב המארח בסיום.

---

## 🎯 המטרה
לחסוך את הצורך בהתחברות ידנית מחדש לחשבון גוגל (ולאימותים דו-שלביים / 2FA) בכל פעם שעובדים על מחשב ציבורי, משותף או חדש – תוך שמירה על רמת אבטחה מקסימלית:
1. **תוכנה ניידת (Portable):** היישום וקובץ הנתונים המוצפן (`chrome_profile.vault`) יושבים יחד על דיסק-און-קי (USB Drive) או בכל תיקייה שתרצה.
2. **הצפנה חזקה ומוגנת בקוד גישה:** הנתונים מוצפנים באמצעות **AES-256-GCM** וגזירת מפתח מאובטחת **PBKDF2** (עם 300,000 איטרציות ו-Salt רנדומלי). ללא קוד הגישה, איש אינו יכול לקרוא את המידע.
3. **ניקוי עקבות מלא:** כפתור ייעודי שמוחק לחלוטין את נתוני הפרופיל מהמחשב הציבורי בסיום העבודה.

---

## 🚀 תרחיש שימוש אופייני (Workflow)

### שלב 1: שמירת הפרופיל במחשב האישי שלך (פעולה חד-פעמית)
1. ודא שדפדפן Google Chrome מחובר לחשבון הגוגל שלך כרגיל.
2. סגור את כרום.
3. הפעל את היישום (דרך ממשק גרפי או פקודה).
4. הזן **קוד גישה / סיסמה** אישית.
5. לחץ על **"1. שמור פרופיל ליישום (גיבוי מוצפן)"**.
6. נוצר קובץ מוצפן בשם `chrome_profile.vault` בתוך תיקיית היישום (או בדיסק-און-קי).

### שלב 2: שימוש במחשב ציבורי
1. חבר את הדיסק-און-קי למחשב הציבורי והפעל את היישום.
2. הזן את קוד הגישה ולחץ על **"2. שחזר פרופיל למחשב (טעינה)"**.
3. פתח את כרום במחשב הציבורי – החשבון שלך מחובר בדיוק כפי שהיה!
4. **בסיום העבודה:**
   - סגור את כרום.
   - ביישום, לחץ על **"3. מחק פרופיל מהמחשב (ניקוי עקבות)"**.
   - נתוני הפרופיל שלך נמחקים לצמיתות מהמחשב הציבורי, והם נשארים אך ורק בתוך הדיסק-און-קי שלך.

## 🛠️ הפעלת היישום

### 1. הפעלה עם ממשק גרפי (GUI)
לחיצה כפולה על קובץ היישום, או הרצה דרך שורת פקודה:
```bash
python main.py
```
יפתח ממשק גרפי ידידותי וברור בעברית המאפשר:
- בחירת פרופיל (Default או פרופיל ממוספר).
- הזנת קוד גישה עם אפשרות הצגה/הסתרה.
- סטטוס זיהוי קובץ הכספת וגודלו.
- כפתורי שמירה, שחזור ומחיקה מהמחשב.

### 2. הפעלה דרך שורת הפקודה (CLI / סקריפטים)
היישום תומך גם בפקודות אוטומטיות מלאות:

- **שמירת פרופיל מהמחשב ליישום:**
  ```bash
  python main.py export -p "הקוד_הסודי_שלך"
  ```
- **שחזור פרופיל מהיישום למחשב:**
  ```bash
  python main.py restore -p "הקוד_הסודי_שלך"
  ```
- **מחיקת הפרופיל מהמחשב הציבורי (ניקוי עקבות):**
  ```bash
  python main.py wipe
  ```
- **בדיקת סטטוס ונתיבים:**
  ```bash
  python main.py info
  ```
- **הצגת רשימת פרופילים קיימים:**
  ```bash
  python main.py list
  ```

## 📦 בניית קובץ הרצה יחיד ועצמאי (Windows .exe)
רוצה לקבל קובץ `ChromeVault.exe` עצמאי שרץ בדיסק-און-קי בכל מחשב Windows ללא צורך בהתקנת Python?

1. הרץ את הקובץ:
   ```cmd
   build_exe.bat
   ```
2. בסיום הבנייה ייווצר בתיקייה הקובץ **`ChromeVault.exe`**.
3. העתק את `ChromeVault.exe` לדיסק-און-קי – וזהו! היישום מוכן לעבודה מלאה בכל מחשב.

## 🔒 אבטחה ופרטיות
- **הצפנה מתקדמת:** כל נתוני המשתמש נארזים ומוצפנים ב-AES-GCM (Authenticated Encryption). שום תוכן אינו נשמר כטקסט קריא.
- **התעלמות ממטמונים:** קבצי מטמון זמניים (Cache), לוגים וקבצי נעילה מסוננים החוצה כדי לשמור על גודל קובץ קומפקטי ומהירות מירבית.
- **הגנה מ-Path Traversal:** מנגנון השחזור בודק ומאמת שכל הקבצים נפרקים אך ורק לתיקיית הפרופיל המיועדת.

### 💡 הערה טכנית חשובה לגבי Windows (DPAPI)
במערכת ההפעלה Windows, דפדפן Chrome מצפין עוגיות התחברות באמצעות מנגנון ה-DPAPI של המשתמש במחשב המקומי. המשמעות היא:
- **בשימוש חוזר באותו מחשב (למשל עמדה קבועה בספרייה/אוניברסיטה/מקום עבודה):** שמירת הפרופיל, מחיקתו בסיום, ושחזורו מחדש באותה עמדה בפעם הבאה – מחזירים את החיבור לחשבון בצורה חלקה ומלאה!
- **במעבר בין מחשבי Windows שונים לחלוטין בעלי חשבונות משתמש שונים:** כל המועדפים, היסטוריה, תוספים וההגדרות ישוחזרו באופן מלא, אך עבור חיבור לחשבון ייתכן שגוגל תבקש אימות מחדש עקב הגנת ה-DPAPI הייחודית לכל מחשב Windows.
